# 908 — Typography and Iconography

**Status:** Proposed  
**Audience:** Product design, UI engineering, desktop-shell, QA, and coding agents  
**Canonical:** Yes

---

## Typography

- Display/headings: **Inter Display**, 600–700.
- UI/body: **Inter**, 400–600.
- technical values: **DejaVu Sans Mono** initially, replaceable by a vetted bundled mono face.

Reference sizes:

- workspace title: 24 px;
- section title: 14–16 px;
- control/body: 13 px;
- compact labels: 11–12 px;
- metadata: 10–11 px;
- technical value: 12 px mono.

Use tabular numerals for timers, coordinates, bitrate, frame rate, and meters.

## Iconography

Default family: **Hugeicons Stroke Rounded**.

Rules:

- 16 px compact control;
- 18 px standard control;
- 20 px navigation;
- 1.7–1.9 px perceived stroke;
- filled icons only for status or unmistakable active state;
- custom Mirae icons for production concepts not covered consistently.

The Mirae mark is a brand asset, not a general navigation icon.
