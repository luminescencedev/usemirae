# 919 — Preview Program and Studio Mode

**Status:** Proposed  
**Audience:** Product design, UI engineering, desktop-shell, QA, and coding agents  
**Canonical:** Yes

---

## Core Distinction

- **Preview** is the prepared next composition.
- **Program** is the currently broadcast/recorded production surface where applicable.

Labels remain visible. Program uses a restrained red operational border and live timer when active.

## Studio Controls

- Cut;
- Auto transition;
- selected transition type/duration;
- Preview/Program swap where supported;
- transition progress;
- take safety states.

## Keyboard

Dedicated shortcuts target Preview, Program, Cut, Auto, and scene selection. Shortcuts are disabled or remapped when text input owns focus.

## Failure

If Preview fails, Program continues. If Program output is degraded, the UI prioritizes impact, recovery, and unaffected outputs.
